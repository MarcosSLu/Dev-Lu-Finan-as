# 💰 Dev Lu Finanças

Aplicativo de **controle financeiro pessoal** desenvolvido com React Native e Expo. O projeto permite registrar e acompanhar receitas e despesas, consultar saldo e filtrar movimentações por data.

## 📱 Funcionalidades

- Cadastro e login de usuários
- Persistência de autenticação
- Cadastro de receitas e despesas
- Listagem de movimentações
- Consulta de saldo
- Exclusão de movimentações
- Filtro por data através de calendário
- Perfil do usuário e logout
- Drawer Navigation personalizado

## 🚀 Tecnologias

- React Native
- Expo
- JavaScript
- React Navigation
- Context API
- Axios
- AsyncStorage
- Styled Components
- React Native Calendars
- Date-fns

## ⚙️ Como executar

Clone o repositório:

```bash
git clone https://github.com/MarcosSLu/Dev-Lu-Finan-as.git
```

Entre na pasta:

```bash
cd Dev-Lu-Finan-as
```

Instale as dependências:

```bash
npm install
```

Execute:

```bash
npx expo start
```

Depois, utilize o **Expo Go** ou um emulador para executar a aplicação.
